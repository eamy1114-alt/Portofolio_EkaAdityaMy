PORTOFOLIO EKA ADITYA MAULANA YUSUF

CARA MEMBUKA:
1. Ekstrak seluruh isi ZIP (jangan buka index.html langsung dari ZIP).
2. Pastikan index.html, .nojekyll, dan folder assets ada di direktori yang sama.
3. Buka index.html dengan Google Chrome, Edge, atau Firefox.

CARA MENGUNGGAH KE GITHUB PAGES:
Upload index.html, folder assets, .nojekyll, dan README.txt ke root repository.
Settings > Pages > Build and deployment: Deploy from a branch > main / (root) > Save.

CATATAN PRIVASI:
Dokumen CV, sertifikat, dan HKI dapat berisi data pribadi. Tinjau sebelum memublikasikan situs.
Dokumentasi internal operasional Telkom tidak disertakan untuk menjaga kerahasiaan kerja.

Semua tautan lihat dan download PDF bekerja bila seluruh isi folder dipertahankan.
